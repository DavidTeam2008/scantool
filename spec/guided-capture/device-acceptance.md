# Device Acceptance: 引导取景（guided-capture）

**前置**：T030 前完成 T000~T023；代码与单测已交付；本文件是真机验收清单。
**设备**：iPhone 13 · iOS 26.7（主）；平整 A4 一张；折页书/摊开书各一本。
**构建**：debug 包；设置中开启诊断（默认 debug 开启）；飞行模式。
**日志**：`log collect --device-udid <UDID> --last 1h` 事后回溯；诊断包从
设置页“导出诊断包”生成（JSON + 原图 + 最近 5s 帧 + 截图）。
**合并执行**：`spec/wps-parity-layout/device-acceptance.md` §A 的 L1 取证
并入同一会话（§7）。

## §0 基线（Phase 0，未过不得进 Phase 1）

| # | 动作 | 通过标准 | 结果 |
|---|---|---|---|
| 0-1 | 直接 `make test`（T000 后） | `total=449 passed=448 failed=0 expectedFailures=1` | ☐ |
| 0-2 | 屏幕左缘贴亮标记，拍一张 | 成片左缘**不出现**标记；`canvasMap` round-trip ≤0.5% | ☐ |
| 0-3 | 失败场景取景 10s，导出诊断包 | JSON 含每帧全部 viable + top 8 候选四角/面积/score/containment/tier、droppedCount；可回放 | ☐ |
| 0-4 | 慢慢移动/调角度复现 | 时间戳轨迹能看出锁定转换；慢漂移（1%/帧）是否不解锁有明确结论 | ☐ |

**判读**：

- `canvasMap`：`roundTripError` 以短边比例记；>0.005 即失败。
- `candidateDump`：右页若在池但输给整书 → 评分/意图问题；不在池 → 检测
  问题。两种都记录，不在此阶段修。
- `lockTrace`：`frozenQuad` 在页面移动时是否保持；若是，记录“慢漂移复现”。

## §1 折页书右页（主场景，SC-001~003）

**动作**：文档模式 → 引导 → 右页；框住右页，拍摄 10 张（近/中/远，含 3 次
翻页）；每张记录耗时；再故意把框拖到含折痕，确认成片忠实执行（用户意图）。

| # | 检查 | 通过标准 | 结果 |
|---|---|---|---|
| 1-1 | 首屏默认框 | 在右页区域内，完全可见；无需先拖到屏幕外 | ☐ |
| 1-2 | 拖动四角 | 44pt 可命中；框保持凸；非法拖动回退不闪 | ☐ |
| 1-3 | 框静止 | 无用户输入时 10s 零自动移动；无红/白状态跳变 | ☐ |
| 1-4 | 成片 = 框 | 右页 10/10、全场景 20/20 只含框内；右页子集左页主体/折痕/背景 0 次入片 | ☐ |
| 1-5 | 四角误差 | 导出照片与截图框对照 ≤短边 0.5% | ☐ |
| 1-6 | 快门前后 | 框不变；无快门后重检/换框 | ☐ |
| 1-7 | 耗时 | 首次对位+拍摄 ≤5s；翻页后 ≤3s | ☐ |
| 1-8 | 日志 | `guidedCapture` 有 intent/框/canvasError/耗时；`cropGate stillArea=-1` | ☐ |
| 1-9 | 自动对位 | 点一次能贴合页面；无候选时 no-op；撤销回原框 | ☐ |

**日志判读**：

- `guidedCapture mode=guided intent=rightPage guide=[...] crop=[...]`：
  `guide` 与 `crop` 应相同（允许 ≤0.5% 映射误差）。
- `cropQuad tag=guide`：成片四角来源；`tag=still/displayed` 在 guided 路径
  不应出现。
- `cropGate displayedArea≈guide.area stillArea=-1 iou=-1 acceptedStill=false`：
  引导直裁，未重检。
- `guideAdjust corner=... shift=... rejected=...`：吸附 ≤0.03；rejected 只在
  非法拖动出现。

## §4 摊开书与 Review 拆分（US4 / SC-006）

**动作**：自动模式拍整书 5 张；进入 Review，确认提案可见；分别选整页/左页/
右页；撤销；再拍 5 张引导页确认不生成提案。

| # | 检查 | 通过标准 | 结果 |
|---|---|---|---|
| 4-1 | appear 后 | 拆分不自动改 quad；身份锚定精修可发生，预览显示其精修结果 | ☐ |
| 4-2 | 拆分提案 | 分割线可见；低置信虚线/弱提示；不自动应用 | ☐ |
| 4-3 | 拖分割线 | 线跟手；应用后 quad 可验证 | ☐ |
| 4-4 | 左/右/整页 | 三种选择结果正确；整页恢复 quadBefore | ☐ |
| 4-5 | 撤销 | 恢复 quadBefore；可再次应用 | ☐ |
| 4-6 | 引导页 | `userAdjustedQuad=true`，不生成提案 | ☐ |
| 4-7 | 日志 | `reviewSplit` 有 proposal/selection/applied/undone | ☐ |
| 4-8 | 误裁 | 0 次静默误裁；10/10 可一键修正 | ☐ |

**判读**：`reviewSplit proposalU=... source=spine prominence=... continuity=...
confidence=... selection=right applied=true`；若 `applied=true` 但用户没有
点应用，即失败。
