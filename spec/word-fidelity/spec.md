# Spec: Word 导出保真度（word-fidelity）

**状态**：Phase 0 已交付（图片版档位 + 裁切修复 + 校验闸门）；Phase 1 待做（可搜索图片版等）
**评估与取证**：[`docs/16-word-export-fidelity.md`](../../docs/16-word-export-fidelity.md)
**前置**：`spec/wps-parity-layout`（档位与流式/版面还原两档）、
`spec/guided-capture`（引导取景 → 精确框选，替代自动页面定位）
**目标平台**：iOS 18+（导出与渲染验证在 macOS 宿主侧完成）

## 背景

用户实测：「稍微复杂一点的图片内容，最后生成 word 的样式会乱掉」。复现样本
`docs/media/IMG_7544.jpg`（教科书右页：横幅标题 / 圆角提示框 / 深色表头表格 /
双栏编号列表 / 灰底词框 / 照片 / 页码 / 页脚）。

WPS 参考录屏（`docs/media/3ca8ce818cf785798a1661a3eef67730.mp4`）显示：竞品的
「扫描件 → Word」产物**就是页面本身**（导出预览渲染页面图、文档提示「只读」），
可编辑文字是另一个独立入口（「提取文字」）。本项目此前的「版面还原」档
（底图 + 净化 mask + 浮动文本框原位重排）**在竞品里没有对应物**，也正是
「样式乱掉」的来源。

同时定位到第二个独立问题：相册导入时，**页面外框检不出**（书页边缘不直 + 透视 +
页面充满取景），静帧检测必然选到页面里的子框（表格框 / 底边条）→ 整页被裁成
一小块（用户实测「只识别了右页的一部分」）。

## 用户故事

- **US1**（P1）复杂页面的 Word 保真：用户把一张教科书页扫/导入后导出 Word，
  得到的文档**看起来就是那一页**（表格、图、色块、页码位置全对），不出现
  文字重复/错位/叠字。
- **US2**（P1）不丢内容：任何情况下，**不得**把整页裁成页面里的一小块；
  认不出页面时宁可不裁（保留整图 + 背景），也不裁错。
- **US3**（P1）可复现的验收：一条命令（`make word-fidelity`）把「导出 → 渲染成图
  → 与原图比相似度」跑完并给出判定，用户口径 **SSIM ≥ 0.90 算通过**。
- **US4**（P2）可编辑仍然可选：图片版成为默认后，「流式」「版面还原」两档
  （可编辑）在设置里一键切换，既有导出能力不丢。

## 功能需求

### FR-001 静帧页面判定（不丢内容）
- 静帧检测的胜出框必须是**页面级**的（覆盖画面 ≥ 50%），或**不裁**（整图当页面）；
- 绝不把页面裁成页面里的子框（表格框 / 色块 / 底边条）；
- 判据是纯函数（可单测），见 `DetectionStrategy.stillPageCandidate`。

### FR-002 图片版导出（样式不可能乱）
- 新增档位「图片版」：每页 = A4 贴合尺寸的页面 + 一张铺满该页的整页图；
- 产物**零浮动文本框 / 零 mask / 零重排**；
- 页面尺寸 = 图片比例在 A4 内的贴合（不留余量、不拉伸）；
- 图片用内联图（`wp:inline`），承载段落行高钉成图高（`lineRule="exact"`），
  段落标记不设 1pt 字号；
- 导出前预览 = 导出产物（同源同形）。

### FR-003 可编辑档不回归
- 「流式」「版面还原」两档的产物结构与既有断言**零修改**（`SpreadSplitter` 纯函数
  与 `DocxRestoredLayoutTests` 全部保持）。

### FR-004 档位体系与默认
- `R2OutputTier` / `ExportTier` 增第三档「图片版」；
- **默认档 = 图片版**（依据：WPS 实测 + 用户实测「样式会乱」；文字检索由 App
  自身 OCR 索引承担）；
- 档位偏好持久化语义不变（未设置/非法值回退默认档）。

### FR-005 保真度校验闸门
- `make word-fidelity` 一条命令完成：导出夹具产物 → 渲染 docx → 算 SSIM → 判定；
- 渲染器 = macOS QuickLook（`qlmanage`，系统自带 Word 预览器）；
- 指标口径固定：缩放 800×800 + 高斯模糊 sigma=3（亚像素错位容差）→ SSIM；
- 门限：**导出保真度 SSIM（渲染图 vs 页面图）≥ 0.90**；同时打印用户口径
  （渲染图 vs 原始照片）；
- 产物落在 `build/word-fidelity/`，可作为验收证据留档。

### FR-006 纯离线
- 导出与校验全程本地文件操作，不引入任何网络依赖（铁律 3）。

## 成功标准

- **SC-001** IMG_7544 夹具：图片版 docx 渲染图 vs 页面图 **SSIM ≥ 0.90**
  （实测 0.914）；用户口径（vs 原始照片）**≥ 0.90**（实测 0.919）。
- **SC-002** 同一夹具的「版面还原」档（对照）**明显低于门限**（实测 0.767）——
  证明闸门有鉴别力，不是「怎么都过」。
- **SC-003** 静帧检测在该夹具上**不裁到子框**：给出页面级框或不裁（单测断言）。
- **SC-004** 自动路径零改动：既有断言零修改；`make test` 全绿。
- **SC-005** 闸门可复跑：`make word-fidelity` 在无网环境下一条命令出结论。

## 边界与例外

- 图片版**不可逐字编辑、Word 内不可搜索**（可编辑两档仍在）；
- 「不裁」意味着画面里可能带背景（用户可 Review 拖角裁切 / 用引导取景框）；
- 校验依赖 macOS QuickLook；其他平台需换渲染器（口径不变）；
- 夹具目前 1 张（真实教科书页），应扩到 10–20 张（整书/双栏/表格/票据/手写）。

## 不在本周期范围

- 图片版 + 隐藏文字层（可搜索的图片版）；
- 自动页面定位（更强的分割/边缘模型）——另立周期，本周期用「不裁 + 手动裁 +
  引导框」兜底；
- PDF 导出的档位化（PDF 走独立通路，不区分档位）。
