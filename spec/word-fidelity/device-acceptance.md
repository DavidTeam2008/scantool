# Device Acceptance: Word 导出保真度（word-fidelity）

**前置**：T001~T005 已交付（`make test` 448 全绿）。
**设备**：iPhone（相册导入路径）+ macOS 宿主（渲染与比对在宿主侧完成）。
**构建**：debug 包；离线（飞行模式）可跑完全流程。
**产物目录**：`build/word-fidelity/`（页面图 + 两种 docx + 渲染图 + 诊断文本）。

## §1 主机闸门（`make word-fidelity`）

| # | 检查 | 通过标准 | 结果 |
|---|---|---|---|
| 1-1 | `make test-only T=WordFidelityExportTests` | 产出 `page.jpg` / `out-pageimage.docx` / `out-restored.docx` / `reference.jpg` | ☐ |
| 1-2 | 图片版 docx 渲染（qlmanage） | 渲染出整页（**非空白**），表格/图/色块/页码位置与页面图一致 | ☐ |
| 1-3 | SSIM(渲染图, 页面图) | **≥ 0.90**（实测 0.914） | ☐ |
| 1-4 | SSIM(渲染图, 原始照片)（用户口径） | **≥ 0.90**（实测 0.919） | ☐ |
| 1-5 | 对照：版面还原档 SSIM | **< 0.85**（实测 0.767）——闸门有鉴别力 | ☐ |
| 1-6 | 渲染图目视 | 同一行文字**不出现两份**，无叠字/错位 | ☐ |

**判读**：SSIM 口径固定（800×800 + 高斯模糊 sigma=3）——换口径数字不可比；
文字密集页的 SSIM 对亚像素错位极敏感，**必须**带模糊容差。

## §2 剪影对照（现状证据）
