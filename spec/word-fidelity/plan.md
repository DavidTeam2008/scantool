## 设计决策

### D1 静帧页面判定：宁可不裁，不裁错（FR-001）
- 纯函数 `DetectionStrategy.stillPageCandidate(viable:)`：
  ① 大候选（≥50%）= 页面；② 候选铺满整幅（并集外接框 ≥60%）→ **不裁**（返回 nil，
  调用方回退 `.fullImage`）；③ 否则（票据/收据类子区域）取最大候选。
- 取舍：裁错 = 内容丢失（不可逆）；不裁 = 多了背景（可逆）。
- 相机实时路径**不动**（近满幅=整幅误检的既有防护保持）——两套语义必须分开。

### D2 图片版 = 整页图铺页（FR-002）
- 页面尺寸：A4 内按图片比例**贴合**（不留余量、不拉伸）；
- 图片：**内联图**（`wp:inline`）；
- 承载段落：行高**钉成图高**（`w:lineRule="exact"`）+ 段落标记**不设** 1pt 字号；
- 零浮动文本框 / 零 mask / 零重排 → 版面不可能乱。

### D3 默认档翻转（FR-004）
- 默认 = 图片版；依据 E1 + 用户实测「样式会乱」+ 文字检索由 App 自身 OCR 索引承担。
- 方向性翻转逐条记录在 `tasks.md`（`ReconstructTierTests` 4 处 + 默认档断言）。

### D4 预览 = 导出（FR-002）
- 「还原版面」预览在图片版档显示**整页图**（`PageImageCanvas`），与导出产物同源同形；
  可编辑两档维持既有预览（块流 / 版面画布）。

### D5 校验闸门：宿主侧渲染 + SSIM（FR-005）
- 渲染：macOS QuickLook（`qlmanage -t`）——系统自带 Word 预览器，零依赖、离线；
- 指标：SSIM，口径 = 缩放 800×800 + 高斯模糊 sigma=3（E6 的对齐容差）；
- 双口径打印：导出保真度（vs 页面图，**门限**）+ 用户口径（vs 原始照片）；
- 夹具产物由**测试**产出（`WordFidelityExportTests` 写 `build/word-fidelity/`），
  校验脚本只读该目录 → 校验不依赖 App 交互，可进 CI。

### D6 纯离线（FR-006）
- 导出/渲染/比对全程本地文件操作；`qlmanage`/`ffmpeg` 是宿主工具，非 App 依赖。

## 不变式

- 自动拍摄路径（检测/粘滞/平滑/冻结/快门）零改动；
- `ServiceProtocols.swift` 既有协议签名零改动（`R2OutputTier` 枚举**增档**是允许的
  变更，`EdgeDetecting` 等协议不动）；
- 既有测试断言零修改，方向性翻转逐条记录；
- 可编辑两档的产物结构不变（`DocxRestoredLayoutTests` 零改动）；
- 纯离线。

## 风险表

| 风险 | 缓解 | 观察 |
|---|---|---|
| 图片版不可编辑 → 用户价值下降 | 可编辑两档保留 + 一键切换；后续做「图片 + 隐藏文字层」 | 档位切换率 |
| 「不裁」让背景进成片 | 手动裁切（Review 拖角）/ 引导取景框（D3 of guided-capture） | 导入后裁切率 |
| QuickLook 渲染与其他渲染器有差 | 口径（缩放+模糊+SSIM）固定；结构断言（零文本框/零 mask）作为第二道闸 | 跨渲染器复测 |
| 静帧「不裁」让票据类小文档不再自动裁 | 判据 ③ 保留子区域裁剪；用更多样本回归 | 票据/收据样本 |
| SSIM 口径漂移 | 口径写死在 `check.sh` 注释里 + spec FR-005 | 数字可比性 |

## 验收流程

1. `make test-only T=WordFidelityExportTests` → 产出夹具产物；
2. `make word-fidelity` → 渲染 + SSIM + 判定（图片版 ≥0.90）；
3. `make test` → 全量绿（基线 449）；
4. 人工看渲染图（`build/word-fidelity/` 留档）确认「看起来就是那一页」。
