## 背景

真机反馈（2026-10-17，折页书场景：书本折起只拍右页，左缘 = 折痕）：

> 取景框一直在抖动，没有捕获到页面边框，会自动拍，拍出来的效果左边折痕
> 还是有一点，其它地方沿着边框裁剪的。

四个痛点 = 四条独立机理（四读者合成，括号内为本周期修复位）：

1. **抖动**：三级检测门控使候选池逐帧近似单源，右页/整书以存在性交替
   出现；近摄制式下两候选 bbox IoU 升至 [0.60, 0.70)，粘滞分支③
   「相似跟随」（阈值 0.60）把交替吞成跟随——锚点逐帧棘轮，areaJump
   反复重置，永不锁定（regime c，case-b-sticky-v2 未覆盖的制式）
   （→ FR-004）；
2. **边框捕获失败**：live 严格矩形档参数（minSize 0.25 / 容差 20°）对
   折页曲面页结构性过严——正确候选不存在于池中，稳定层只能在
   「稳定地错」与「抖动着错」之间二选一（→ FR-003）；
3. **自动拍**：锁定判定只有几何稳定维度，整书 quad（面积 0.85~0.94、
   边距 0.02~0.05）恰好绕过 `isSuspiciousForAutoCapture`，确认窗
   6 帧后自动拍出废片（→ FR-001 默认不自动拍 + FR-002 提示门控）；
4. **折痕入片**：`EdgeSnapper` 仅外向搜索——检出左缘已越过折痕带时
   真实边缘在内侧，外推够不着（→ FR-006 双向两阶段）。
   另：门禁「呈现框优先」决策在整理页被 `refineQuads` 无条件 still
   重检穿透（「锁的是右页、存的是整书」会在整理页复活）（→ FR-007）。

## 用户故事

- **US1**（P1）拍折页书右页时实线取景框稳定：不再逐帧跳动，可在锁定
  窗内锁定，锁定对象为右页。
- **US2**（P1）边框自动检测正确：候选池中存在真实页面矩形，择优与
  粘滞锚定右页而非整书外轮廓。
- **US3**（P1）成片 = 取景框所见：手动拍/自动拍（显式开启后）的成片
  裁切框与快门瞬间屏幕呈现框一致，且不被整理页自动精修覆盖；左缘
  不含折痕带。
- **US4**（P1）默认不自动拍：全新安装/从未设置过的用户快门主导权在
  手；显式开启过的用户选择保留。

## 功能需求

- **FR-001** `PreferencesStore.autoCapture` 默认 true→false。**零迁移**：
  didSet 在 init 内不触发，未显式设置的用户无持久化键 → 默认翻转自然
  生效；显式设置过的用户键已落盘 → 选择保留。不得添加迁移代码（会
  覆盖显式选择）。
- **FR-002** 可疑锁定提示（`isAutoCaptureSuppressed` 置位 +
  `ZhixiaLog.suspiciousLock` + 确认窗冻结）整段仅在
  `preferences.autoCapture` 开启时生效——默认不自动拍时没有可抑制的
  快门，提示与日志（autoCapture=suppressed 字样）都是误导。
- **FR-003** live 严格矩形档放宽：minimumSize 0.25→0.15、
  quadratureTolerance 20°→26°（minimumConfidence 0.6 不动）。仅 live
  首档（`detectRectangles(relaxed: false)`）；still 首跑即放宽档、
  live 第三级放宽档（0.35/0.08/28°）均不动——取中间值避免一步跳到
  放宽档噪声水平。
- **FR-004** live 粘滞调用点参数覆盖（`CandidateSticky` 默认常量不动，
  铁律 2）：`similarityThreshold: 0.70`（regime c 止棘轮：同候选跨帧
  抖动 IoU ≥0.85 不受影响，近摄异候选 0.60~0.70 判跳变走 hold）、
  `missLimit: 5`（5 帧 ≈0.33s@15fps < 0.5s 移场接受上限，逃逸不粘死
  语义不变）。
- **FR-005** `QuadSmoother` 保持默认 missLimit 3（**刻意的非对齐**）：
  smoother 的 miss 保留只管「全帧无检出」的呈现框存留（0.2s 消失
  语义不变）；存在性交替下 sticky 每帧回传锚点择优，smoother 的 miss
  路径本就不触发。（曾设计同步拉长到 5，因
  `AutoCaptureHoldWindowTests/holdWindowResetsOnUnlock` 钉住 3 帧失锁
  语义而回退——见 tasks.md 方向性翻转记录。）
- **FR-006** `EdgeSnapper` 双向两阶段（逐边独立）：① 外向相（既有
  语义不变）s ∈ [0, maxShift] 找最强「页内亮 − 页外暗」正梯度；
  ② 外向无有效梯度（< 0.08）的边回落内向相：s ∈ [−0.5×maxShift, 0)
  找同一签名的正梯度峰，阈值 1.5×（0.12）。限幅减半（≈短边 2.5%，
  页边距普遍远大于此）+ 阈值提高 + 沿边 5 点均值——三重文字笔画
  防御（内拉误吸 = 直接裁掉内容，宁缺毋滥）。四项校验语义不变。
- **FR-007** `PageDraft` 新增 `gateRejectedStill: Bool = false`：
  快门门禁「呈现框优先」决策（有呈现框 ∧ 弃用静帧）置位；
  `ReviewViewModel.refineQuads` 跳过置位页——WYSIWYG 契约贯穿到
  保存路径。搜索态自由检测/静帧精修采纳/idCard 路径不置位，
  refine 照旧；`userAdjustedQuad` 语义不变。
- **FR-008** 既有断言零修改（铁律 2）：全部行为变化由新增测试钉住；
  `ServiceProtocols.swift` 零改动（铁律 1）。

## 成功标准

- **SC-001** 折页书拍右页：实线框 ≤5s 稳定不跳，0.55s 窗内可锁定，
  锁定对象为右页（真机，device-acceptance §1）。
- **SC-002** 手动拍成片 = 快门瞬间呈现框；显式开启自动拍后锁定拍
  成片 = 锁定框（真机 §1/§2）。
- **SC-003** 成片左缘不含折痕带（内向相吸附生效），其余三边贴边
  精度不回归（真机 §1 对照 + 平整文档防回归 §3）。
- **SC-004** 新装/未设置用户默认不自动拍；显式开启用户升级后设置
  保留（单测 PreferencesStoreTests ×3 + 真机 §2）。
- **SC-005** `make test` 全绿：377 = 376 passed + 1 expected failure
  + 0 failed（基线 368 + 新增 9，只增不减）。

## 边界与例外

- 同候选跨帧 IoU ∈ [0.70, 0.85) 的极端近摄制式：0.70 阈值下仍判
  跳变走 hold——hold 维持的是锚点原样，输出不翻转，仅损失小幅
  跟随漂移，可接受（真机观察 stickyHold 比例回填评估）。
- 折痕带极宽（> 短边 2.5%）时内向相限幅够不着真实边缘 → 原样返回
  （宁可不修），成片仍含部分折痕——用户手动调框路径不变。
- 平整文档/证件/相册导入路径：除 FR-001（默认值）与 FR-002（提示
  门控）外零行为变化。
