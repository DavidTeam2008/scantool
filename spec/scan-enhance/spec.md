# Spec: 拍后增强（scan-enhance）

**状态**：实施中（真机验收待做）
**前置**：`spec/frame-truth`（框真相）、`spec/folded-page-capture`
**诊断来源**：2026-10-20/21 真机复测（14 张截图 + 逐帧遥测）与竞品
（WPS 万能扫描 / 扫描全能王）流程对标

## 背景

真机反馈（2026-10-20）：取景侧仍有两类无法靠 live 链路解决的问题：

1. **摊开书场景候选池里只有「整书」一个候选**（日志：`strict/seg ≈ 0.43–0.49`，
   无任何单页候选——右页在场景中不是独立矩形）。用户只想拍右页 → 取景框
   含折起部分、成片也含。
2. **单页场景左缘精度/稳定性不足**：live 检测框 ≈0.22 存在，但左缘只在
   书脊附近摆动，偶发切到折痕外；用户来不及在正确瞬间按快门。
3. 竞品流程：拍后**重新做边框检测和裁剪**（取景检测不精确没关系）、
   去皱/去除中间折痕、清晰化，再识别排版导出 Word。

本周期按竞品流程把「精确裁切」从取景时刻移到**整理页的拍后处理**：
快门框仍 = 呈现框（frame-truth 契约不变），整理页用全分辨率静帧重检
（带身份锚定）+ 书脊拆分，结果直接显示、可再调。

## 功能需求

- **FR-001 拍后全分辨率重检 + 身份锚定**（`ReviewViewModel.refineQuads`）：
  静帧候选与拍摄框 `IoU ≥ 0.85` 才采纳（高分辨率检测含贴边吸附）；否则
  保留拍摄框（防「右页 vs 右页+折痕」外框漂移）。`.fullImage` 兜底页无身份
  可言，直接采纳静帧结果。用户拖过角的页跳过。
- **FR-002 拍后裁切两模型**（`SpreadSplitter`，Domain 纯函数；2026-10-21
  真机照片实测修订）：
  1. **左侧折痕暗条**（场景 2）：折起部分在校正图左侧是一条**暗带**
     （实测 u≈0.08、暗度 0.44），从左侧找第一个「持续明亮」的列作为右页
     左缘裁掉折条（暗条宽 ≥4%、暗度 ≥0.15 才生效）；
  2. **中央书脊暗谷**（场景 1）：亮左页的摊开书走暗谷模型——密集列扫描
     （0.6% 步长）+ **局部凹陷评分**（每列只看左右各 4% 邻域；全局最暗列
     会被页面内深色插图带偏，真机日志落在 u=0.72）+ 谷深 ≥0.06 + 贯穿性
     ≥0.7 + 谷宽 ≥1.5% + 矫正图 ≥200px，沿书脊拆出**右页**。
  两模型互补：左折条命中则不跑暗谷；都不命中则保留拍摄框。
- **FR-004 预览可见域钳制**（2026-10-21 真机修订）：预览层是 aspectFill，
  只显示照片中央一部分（真机 390×844 视图、0.75 视频 → 可见照片 x∈[0.19,0.81]），
  照片却覆盖整幅传感器视野——**成片不得包含用户在预览里看不到的内容**
  （真机：折叠部分在"镜头外"却仍在照片里、被裁进成片）。呈现框与裁切逐顶点
  钳制到预览可见域：折叠部分在可见区外时被自然切除，框的越界边贴着屏幕边。
  视图尺寸由 `onGeometryChange` 上报；未测量时不钳制（既有语义）。
  整理页重检同样不得把内容扩回：静帧候选面积 ≤ 拍摄框 × 1.10 才采纳。
- **FR-003 结果可见可调**：拆分/重检结果直接反映在整理页预览；用户拖角
  （`userAdjustedQuad`）优先于任何自动处理；保存/导出使用最终 quad。
- **FR-004 清晰化**：沿用既有增强档（`enhance` 含锐化 0.35、`deskewShadow`
  去阴影）——本周期不做新滤镜；验收确认文档档观感（清晰度/阴影）。
- **FR-005 既有断言**：除 tasks.md 记录的方向性调整外零修改；
  `ServiceProtocols.swift` 零改动；快门契约（frame-truth FR-006）不变。

## 成功标准

- **SC-001** 摊开书（场景 1）：拍整书 → 整理页自动拆为右页（左缘≈书脊），
  成片不含折起部分；用户可拖角修正。
- **SC-002** 单页（场景 2）：拍后左缘被钉到书脊（全分辨率 + 吸附），
  成片不再含左页细条。
- **SC-003** 身份既非漂移：静帧选到含折痕外框时不覆盖拍摄框（IoU 闸）。
- **SC-004** `make test` 全绿：397 = 396 passed + 1 expected failure + 0 failed。
- **SC-005 取景稳定性**：红线/白线不再高频互跳——锁定迟滞 3%（锁定后
  小幅抖动不解锁，明显移动才回到跟踪）。

## 边界与例外

- 书脊检测依赖「贯穿整页的竖向暗谷」；硬壳书/反光书脊谷深不足时不动
  （保留整书框，用户手动调角）。
- 左页拍摄（左手页）暂未提供切换（默认右页）；后续可加左右页切换 UI。
- 整理页重检用检测器既有静帧链路（放宽矩形 + 分割 + 吸附），不改协议。
