# Plan: 拍后增强（scan-enhance）

**Input**: spec.md（FR-001~005）

## 设计决策

- **D1 身份锚定而非全局重选**：静帧重检结果只在 `IoU ≥ 0.85` 时采纳。
  上一轮静帧全局择优曾把「右页+折痕」外框选成赢家（+6.5% 面积）——
  高分辨率重检必须锚定在拍摄对象上。`.fullImage` 例外：搜索态兜底页
  无身份，直接采纳静帧结果（既有 Review 用例依赖此语义）。
- **D2 书脊拆分是场景 1/2 的唯一解**（2026-10-21 真机修订）：整书场景
  候选池里没有单页候选；场景 2 的左框线甚至超出预览可见区（照片内仍在），
  裁切必含左页。拍后在**透视矫正矩形图**上找书脊——逐列（0.6% 步长）
  扫描 y∈[0.1,0.9] 均值 + 谷深 ≥0.06 + **V 形校验**（谷两侧 5% 处都明显
  更亮）+ **贯穿性 ≥0.7** + **谷宽 ≥1.5%**（印刷竖线只有 1–2 个栅格列）
  + **矫正图 ≥200px**（低分辨率下 1px 线会被放大成宽谷）。**去掉宽高比
  门槛**：场景 2 的书脊可能偏左、整体呈竖版。
- **D3 拆分默认右页**：中文书阅读起点；左页拍摄的切换 UI 留待后续
  （结构性留白，不阻塞本轮）。
- **D4 矫正图 + 160 列栅格**（2026-10-21 修订）：首版在四边形空间用双线性
  四角插值采样——书脊暗带只占页宽 ~1.5%，28 列采样漏检、均值被稀释，
  真机一次都没触发。改为与渲染同源的 `CIPerspectiveCorrection` 矫正后
  做密集列扫描（0.6% 步长）；SplitOutcome 全量回填 `refineStage` 遥测
  （capturedArea/stillArea/iou/acceptedStill/aspect/spineU/prominence/
  continuity/splitApplied），下一轮从日志直接定位卡点。
- **D5 快门口径不变**：快门框 = 呈现框（frame-truth FR-006）；整理页的
  重检/拆分是**可见的拍后处理**（预览即结果），不是快门后的隐藏改框。
  `cropIsFinal` 字段随本周期删除（其语义被「整理页可见增强」取代）。

### D6 左侧折痕暗条模型（2026-10-21 照片实测）

场景 2 的折起部分不是「两侧亮的暗谷」而是**左侧一条暗带**（真实照片校正图
剖面：u 0.02–0.06 亮度 0.23–0.39，右页 0.75–0.85）——暗谷模型结构性不适配，
这正是首轮 update 后 `splitApplied` 全为 false 的原因。新增 `leftFoldTrim`：
页面内部亮度取中位数（对深色插图鲁棒），亮阈 = 内部 −0.12，从左侧找第一个
连续 4 列持续明亮的列；暗条宽 ≥4%、暗度 ≥0.15 才裁（区别于裁切边界的
背景余量，避免误裁摊开书的亮左页）。

### D7 锁定迟滞（取景稳定）

真机「红线↔白线高频互跳、已对准提示转瞬即逝」＝锁定态被 1.2% 级抖动反复
打断。`QuadSmoother` 增加 `unlockEpsilon`（默认 = epsilon，既有语义不变）；
live 用 3%——锁定后小幅抖动不解锁、冻结框持续呈现，明显移动（>3%）才回到
跟踪。既有锁定/失锁用例的位移均 ≤1% 或走 miss/areaJump 通道，零翻转。

### D8 预览可见域钳制（2026-10-21 真机修订）

真机：预览 aspectFill 只显示照片中央（390×844 视图 / 0.75 视频 → 可见
x∈[0.19,0.81]），而照片覆盖整幅视野——折叠部分"不在摄像头范围内"只是不在
**预览**内，仍在照片里；检测框（照片空间）左缘到 x≈0.09，裁切必然带折条。
用户提议（框的左边线贴屏幕边）的正确形态 = 把呈现框/裁切钳制到可见域。
实现：`CaptureViewModel.visiblePhotoRect`（由 `previewSize`+geometry 解析
计算，`onGeometryChange` 上报），摄入边界逐顶点钳制；冻结框同钳制。
整理页重检增加「面积 ≤ 拍摄框×1.10」闸，防止把没看见的内容扩回来。

### D9 书脊局部凹陷评分（2026-10-21 真机修订）

真机日志：`spineU=0.72 prominence=0.03–0.045`——全局最暗列被页面内的
深色插图（乐手照片）带偏，真实书脊不是全局最暗。改为逐列**局部凹陷**
评分：`min(mean(u±4%)) − mean(u)` 最大者胜；V 形/贯穿性/谷宽/分辨率闸不变。

## 不变式

- `ServiceProtocols.swift` 零改动；EdgeSnapper 最近峰策略与 s=0 守卫不变。
- 用户拖角页（userAdjustedQuad）零改动。
- 纯离线；idCard/相册导入不拆书脊（宽高比闸自然排除）。

## 风险表

| 风险 | 缓解 | 真机观察 |
|---|---|---|
| 静帧身份与拍摄框不一致导致不重检 | 保留拍摄框（本周期可接受，框已吸附） | refine 后 quad 是否变化 |
| 书脊谷误判（表格线/阴影） | 双闸 + 右页默认；可拖角 | 拆分结果与页面 |
| 大图重复加载（重检 + 拆分各一次解码） | 拆分用 800px 缩略；页数少 | 整理页打开速度 |
