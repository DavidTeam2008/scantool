# Spec: 取景包络跟踪（capture-envelope-tracking）

**状态**：实施中（CF-T001~T005d 已交付；CF-T010 取景域 WYSIWYG / CF-T011a 近距单页
已实施，T011a 由用户确认修复；T010 真机验收记录待补；CF-T010b/T011 未开始）
**当前提交**：`7a546b4`（CF-T005b/c/d + T010 + T011a）
**背景与方案**：[`docs/22-capture-envelope-tracking.md`](../../docs/22-capture-envelope-tracking.md)
**前置**：`spec/frame-truth`（成片 = 呈现框）、`spec/guided-capture`（引导/取证）
**后续任务**：[`tasks.md`](tasks.md) · 真机清单：[`device-acceptance.md`](device-acceptance.md)

## 背景

视频 5/7 真机复现显示：把“用户选择左/右页”直接当成“实时必须锁定单页四边形”
约束过强。彩色/曲面/低对比页面常常没有稳定单页候选，导致取景框消失；无框时
快门回退 `.fullImage`，成片带整摊/桌面。WPS 类产品的稳定感来自持续跟踪一个
书/整摊包络，拍后再拆分和精修。

本周期把取景改为**包络优先**：

- 实时只维护一个稳定的整摊/书/单页 envelope；
- 左/右页作为**输出意图**，拍后在高分辨率原图上落地；
- 无当前帧包络时保持搜索态，**绝不回退整幅画面**；
- 引导/手动框保留为兜底。

2026-10-29 视频 11/12 进一步定位到更底层的约束：预览层 `.resizeAspectFill`
只显示 4:3 帧的 **61.6% 宽**（两侧各裁 19.2%），而检测/成片用整帧——
**取景域 ≠ 成片域**。包络/目标再准，用户仍要举高、屏幕外内容仍参与检测、
成片横向范围是屏幕的 1.62 倍（多出 62%）。CF-T010 把取景域拉回与成片同域，是本周期后续所有
验收的前提。

## 功能需求

- **FR-001 包络观测与显示**：`VisionEdgeDetector.observeEnvelope` 每帧返回
  `envelope` 与可选 `target`；目标页缺失时 envelope 仍可显示。tracker 负责
  hold/平滑/候选切换确认；overlay 始终有包络或明确搜索态。
- **FR-002 屏幕外框拒绝**：近满幅/四边贴边的矩形不是页面；在包络选择、
  `resolve` 书脊拆分、tracker 摄入、快门的全链路拒绝。无当前帧包络或 tracker
  hold 时快门置灰，不写 `.fullImage`。
- **FR-003 目标页显示**：左/右页意图有可靠 target 时，target 是实线主框
  （压暗 + 四角括号）；整摊 envelope 降为淡虚线上下文。左页目标右角必须落在
  书脊上，不因整摊 envelope 超出屏幕而消失。整摊被预览边缘裁掉（宽/面积不够
  `isSpreadLike`）时，允许从包络的**亮缝**推出目标页（FR-009）。
- **FR-004 输出意图持久化**：`PageDraft.outputIntent` 记录拍摄时 left/right；
  whole 记 nil。**FR-008**：`PageDraft.quadRole` 记录快门用的是目标页
  （`.target`）还是整摊包络（`.envelope`）；旧数据 nil。Review 按意图选择
  最终页，用户仍可切换/撤销。
- **FR-005 拍后高分辨率拆分**：Review 首轮精修在 1600px 矫正图上先找书脊
  （暗谷），找不到再找**亮缝**（白内边距/文字间隙）；右页单页框带左折条时
  复用暗/亮折条模型。置信度 ≥0.5 自动落到目标页并压入撤销栈；不足只生成
  预选提案，不静默改写。`quadRole == .target` 的目标框不二次拆分；
  `.envelope` 必须尝试拆分，找不到证据保留包络并记录 `envelopeNoSplit`。
- **FR-006 离线与安全**：全链路纯离线；分割/去畸变模型只能输出 mask/几何，
  禁止 LLM/VLM 生成文档像素；不引入云端调用。
- **FR-007 兜底**：引导模式、手动拖框、相册导入保持可用；自动路径的改动不得
  改变引导路径语义。
- **FR-008 拍摄框角色**：快门快照必须同时记录 `quadRole`（target/envelope），
  Review 不得用宽高比猜角色——被屏幕裁掉的整摊包络可能和单页一样窄。
- **FR-009 亮缝拆分**：`SpreadSplitter.analyzeGutter` 在矫正图上按列亮度均值
  找“比左右内容块更亮”的空白带；作为暗谷书脊失败后的第二模型，接入实时
  `PageIntentResolver` 与拍后 Review。搜索限定在中线 `0.30~0.70`（书脊在
  画面中部；每页内部的两栏间隙在 0.75/0.25 附近——视频 9 的 0.759 误拆）。
  书脊暗谷宽度上限 20%：宽暗区是插图/照片，不是书脊。
- **FR-010 目标页一致性校验**：`resolve` 返回前必须过 `acceptTarget`：
  目标在包络内（2% 贴边容差）、落在意图侧（右页在包络中心右、左页在左）、
  宽高比 `0.45~1.10`、面积 ≥6%（拆分目标）。画面边缘/桌面矩形、页内竖条、
  错误侧候选一律回落到包络或 nil，不得成为实线目标框。
- **FR-011 页对包络与页候选优先**：检测器分别给出左页/右页矩形时，用两页
  并集作为整摊包络（`pagePairEnvelope`），避免“墙 + 书”的大场景矩形被当成
  书/页（视频 10：大矩形宽高比 0.93、上缘到画面 0.05）。`resolve` 先信池里
  符合意图的干净页候选，再做整摊拆分；拆分目标面积门 6%。
- **FR-012 取景域 = 成片域（WYSIWYG，CF-T010）**：预览容器宽高比必须等于
  运行时视频宽高比；预览层不得用 aspectFill 把 4:3 帧裁进 19.5:9 全屏。
  检测、包络、目标、快门、裁切共用该域；`visiblePhotoRect` 退化为全幅。
  视频 11/12：预览只显示 61.6% 帧宽，导致必须举高、屏幕外内容仍参与检测、
  成片横向范围是屏幕的 1.62 倍。
- **FR-015 近距单页裁切（CF-T011a）**：整页意图下包络贴帧边时，
  **单页**（`isPageLike` 且非 `isSpreadLike`）→ 允许拍（裁掉的是纸边白边，
  不是内容），呈现框顶点越出照片域时裁切框钳到 [0,1]；**整摊/整书被裁**
  → 仍不画实线、快门置灰、提示后退（拆页需要完整整摊）。左/右页意图下
  目标页是单页 → 允许贴边拍；目标页缺失 → 允许拍包络回退（Review 拆分），
  不因整摊贴边把整个取景变成不可拍。视频 14（近距右页）/视频 13（左右页
  目标短暂缺失）是此条的直接来源。
- **FR-013 贴边单页（CF-T011）**：左/右页意图下，目标页的书脊侧边落在帧边界
  （±1.5%）且其余三边可见时，用上/下边线与帧边界的交点合成书脊侧边；
  UI 显示 1.5% 内缩引导线与“贴边”徽标，未对齐则不就绪。整页意图禁用；
  对页不得进入帧内。这是高清单页取景，不是整页/左右页的默认路径。
- **FR-014 拍后包含性（CF-T010b）**：`ReviewViewModel.refineQuads` 的静帧
  重检不得把拍摄框外的内容扩回成片。面积 ≤1.10× 与 IoU ≥0.85 不足以表达
  “包含”——改为逐边包含校验（含 1% 吸附容差）；不满足则保留拍摄框。

## 成功标准

- **SC-001 框可见性**：页面可见帧的包络/目标框可见率 ≥95%；无可信页面时
  明确搜索态，不画贴屏假框。
- **SC-002 无 fullImage 误拍**：屏幕外框/整幅 frame 不得落成页面；`capture()`
  与 UI 快门双重守卫。
- **SC-003 左页显示**：左页目标的右上/右下角在书脊上可见；整摊包络可超出屏幕。
  视频 8（2026-10-28）：修复前只可见左上/左下两角、状态“对准纸张”；修复后
  目标右角应落在亮缝（u≈0.547）。
  视频 9（2026-10-28）：右页/左页实线框为页内竖条/画面边缘/整摊；设备日志
  `cropQuad` 显示拍下的是包络（area 0.1966），`reviewSplit proposalU=0.7594`
  是右页栏间距。修复后同一包络的亮缝在 u≈0.509，左/右目标均可解析。
- **SC-004 输出页正确**：彩色/黑白场景下左/右页输出正确率 ≥90%；
  0 内容丢失（标题/页码/表格/插图）；背景残留目标 <5% 页边。
  视频 8 反例：左页成片曾把整摊包络原样保留，右页左栏整列漏入；修复后
  左页成片右缘落在亮缝，不再含右页文字。
- **SC-005 高置信拆分安全**：低置信不自动改写 quad；高置信可撤销；
  无书脊/折条证据时保留整摊，不硬拆。
- **SC-006 回归**：新增用例全绿；全量测试总数不低于 **547**（视频 8 +8：
  gutter 4 / resolver 1 / Review 3；视频 9 +4：gutter 1 / resolver 3；
  视频 10 +1：页对包络；CF-T010 +12：布局 5 / 贴边 5 / viewmodel 2；
  CF-T011a +4：viewmodel 3 / 单页判定 1）；
  WPS realbase **0.906224** 与 docx SHA-256
  `80903b1d…8cf4153` 不回退。
- **SC-007 取景域一致性（视频 11）**：原生相机同高度能拍全的书，App 取景窗
  也能拍全；成片不得出现取景窗外内容；整摊未全入屏时不出可拍实线；
  **单页近距（纸边贴画幅）可拍**，裁切框不越出照片域。
  量化：取景窗宽高比 == 视频宽高比（0.75）；同书入屏距离相对旧版 ×0.62；
  成片内容范围与取景窗一致（边缘差 ≤2%）。
- **SC-008 部分出屏与贴边单页（视频 12/13/14）**：整摊部分出屏时不画可拍实线；
  单页近距（整页或左/右意图）允许拍，裁掉的只是页边白边、内容零丢失；
  右页贴左边界/左页贴右边界时能稳定输出目标页，成片不含对页内容；
  左右页正确率 ≥90%，成片对页残留 <2% 页宽。
- **SC-009 拍后不扩框**：任何 `refineQuads` 采纳的静帧框都必须落在拍摄框
  内（逐边 +1% 容差）；违反时保留拍摄框并记录 `refineRejected=outsideCapture`。

## 边界与例外

- 没有可信书/页面时允许无框（搜索态）；这是正确行为，不是回归。
- 单页/A4 无书脊：左/右意图得到整张单页；不做中心硬拆。
- 折页书只对右页输出使用折条裁切；左页输出不使用 leftFold（避免切出折页窄条）。
- 亮缝模型对“单页两栏”有天然歧义：`.target` 拍摄一律不走亮缝；`.envelope`
  只在裁掉的整摊（中心偏移 + 宽高比 ≥0.95）或拍后角色为 envelope 时使用。
- 彩色页面 mask、内容安全门、透视/去背景不在第一版范围（tasks D/E）。
- **照片 FOV == 视频 FOV 必须在真机验收确认**（同为 4:3 不等于同 FOV）：
  在取景窗四边贴标记物拍摄，静帧检测框在照片空间应落在 [0.02,0.98]；
  若内缩 >2%，说明照片比视频宽，快门时必须把照片裁到视频 FOV 后再落盘
  （T010 验收项，不先写死）。
- 贴边单页只在左/右页意图启用；整页意图、引导框、相册导入不适用。
- 真机相机行为不能由模拟器替代；模拟器只做构建/单测/相册导入。
