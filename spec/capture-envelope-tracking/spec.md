## 背景

视频 5/7 真机复现显示：把“用户选择左/右页”直接当成“实时必须锁定单页四边形”
约束过强。彩色/曲面/低对比页面常常没有稳定单页候选，导致取景框消失；无框时
快门回退 `.fullImage`，成片带整摊/桌面。WPS 类产品的稳定感来自持续跟踪一个
书/整摊包络，拍后再拆分和精修。

本周期把取景改为**包络优先**：

- 实时只维护一个稳定的整摊/书/单页 envelope；
- 左/右页作为**输出意图**，拍后在高分辨率原图上落地；
- 无当前帧包络时保持搜索态，**绝不回退整幅画面**；
- 引导/手动框保留为兜底。

## 功能需求

- **FR-001 包络观测与显示**：`VisionEdgeDetector.observeEnvelope` 每帧返回
  `envelope` 与可选 `target`；目标页缺失时 envelope 仍可显示。tracker 负责
  hold/平滑/候选切换确认；overlay 始终有包络或明确搜索态。
- **FR-002 屏幕外框拒绝**：近满幅/四边贴边的矩形不是页面；在包络选择、
  `resolve` 书脊拆分、tracker 摄入、快门的全链路拒绝。无当前帧包络或 tracker
  hold 时快门置灰，不写 `.fullImage`。
- **FR-003 目标页显示**：左/右页意图有可靠 target 时，target 是实线主框
  （压暗 + 四角括号）；整摊 envelope 降为淡虚线上下文。左页目标右角必须落在
  书脊上，不因整摊 envelope 超出屏幕而消失。
- **FR-004 输出意图持久化**：`PageDraft.outputIntent` 记录拍摄时 left/right；
  whole 记 nil。Review 按意图选择最终页，用户仍可切换/撤销。
- **FR-005 拍后高分辨率拆分**：Review 首轮精修在 1600px 矫正图上找书脊；
  右页单页框带左折条时复用暗/亮折条模型。置信度 ≥0.5 自动落到目标页并压入
  撤销栈；不足只生成预选提案，不静默改写。已是单页的目标框不二次拆分。
- **FR-006 离线与安全**：全链路纯离线；分割/去畸变模型只能输出 mask/几何，
  禁止 LLM/VLM 生成文档像素；不引入云端调用。
- **FR-007 兜底**：引导模式、手动拖框、相册导入保持可用；自动路径的改动不得
  改变引导路径语义。

## 成功标准

- **SC-001 框可见性**：页面可见帧的包络/目标框可见率 ≥95%；无可信页面时
  明确搜索态，不画贴屏假框。
- **SC-002 无 fullImage 误拍**：屏幕外框/整幅 frame 不得落成页面；`capture()`
  与 UI 快门双重守卫。
- **SC-003 左页显示**：左页目标的右上/右下角在书脊上可见；整摊包络可超出屏幕。
- **SC-004 输出页正确**：彩色/黑白场景下左/右页输出正确率 ≥90%；
  0 内容丢失（标题/页码/表格/插图）；背景残留目标 <5% 页边。
- **SC-005 高置信拆分安全**：低置信不自动改写 quad；高置信可撤销；
  无书脊/折条证据时保留整摊，不硬拆。
- **SC-006 回归**：新增用例全绿；全量测试总数不低于 518；WPS realbase
  **0.906224** 与 docx SHA-256 `80903b1d…8cf4153` 不回退。

## 边界与例外

- 没有可信书/页面时允许无框（搜索态）；这是正确行为，不是回归。
- 单页/A4 无书脊：左/右意图得到整张单页；不做中心硬拆。
- 折页书只对右页输出使用折条裁切；左页输出不使用 leftFold（避免切出折页窄条）。
- 彩色页面 mask、内容安全门、透视/去背景不在第一版范围（tasks D/E）。
- 真机相机行为不能由模拟器替代；模拟器只做构建/单测/相册导入。
