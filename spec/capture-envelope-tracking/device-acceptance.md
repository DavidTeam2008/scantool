## 3. 拍后输出检查

- 高置信：Review 首屏直接是目标页；拆分工具可撤销。
- 低置信：首屏出现拆分建议，目标侧预选高亮；用户确认后才写 quad。
- 无书脊/折条：保留整摊，不硬拆。
- 右页单页框带折条：折条被裁掉，正文/页码/表格不丢。
- 左页：不从左侧折条模型裁切；最终页是左页。

## 4. 失败取证

1. 保留录屏时间点 + 原图（如果已拍）。
2. 复制 Console 的 `refineStage` / `reviewSplit` / `cropGate` 行。
3. 记录设备型号、iOS 版本、构建 commit、取景模式、意图。
4. 证据放 `build/capture-acceptance/<date>/`；不要只发截图。
5. 不要为了让单次通过而改断言/阈值；先按 `docs/22` §六定位。
