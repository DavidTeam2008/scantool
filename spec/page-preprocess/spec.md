# Spec: 页面预处理（page-preprocess）

**状态**: 当前周期（2026-10-25 起）
**上游**: 用户真机反馈（Word 可编辑档仍有背景字重影；纸张/文字框不平行、折痕导致识别区域不稳）
**关联**: `spec/word-fidelity/`（导出层）、`docs/19-page-preprocess-plan.md`（执行计划与优先级）

## 1. 问题

当前链路：

```
相册/拍照 → 四角透视矫正 → 增强 → OCR → 版面还原 → Word
```

四角矫正只能把**一个四边形**拉成矩形，不能处理：

1. 纸张/文字框外的桌面、手指、书脊、阴影仍留在页面图里；
2. 书页有折痕、纸张弯曲，文字行/表格边框在矫正后仍然不水平/不垂直；
3. 书页边缘不是直线，单应性变换后左右/上下边框不平行；
4. 上述误差会让 OCR 行切分、表格列边界、可编辑文本框定位都变差；叠加导出层文字后出现背景字重影。

## 2. 用户故事

- **US1**：作为用户，我拍/选一张书页，导出的页面只保留纸张/文字区域，不把桌面和书脊带进 Word。
- **US2**：作为用户，折痕和纸张弯曲不应让文字行歪斜；转出来的 Word 里文字行、表格线应基本水平/垂直。
- **US3**：作为用户，预处理不能吞字、不能把照片/插图裁掉；不能为了“看起来平”而破坏内容。
- **US4**：作为开发者，预处理要可测量、可回归，不能靠单张样张目测。

## 3. 功能需求

- **FR-001 页面边界**：从原图检测纸张/页面四边形；检测不可靠时退回当前四角检测或整图，绝不裁到页面内子框。
- **FR-002 页外裁切**：按页面四边形裁切，保留 ≥1% 安全边；页外背景占比目标 <2%。
- **FR-003 边框拉直**：将页面四边映射为水平/垂直；左右、上下边平行度误差 ≤0.5% 短边。
- **FR-004 折痕/光照**：去除折痕阴影和渐变光照，纸张底色趋于均匀；照片/插图区域不做强去色。
- **FR-005 文字行水平化**：矫正后文字行中位倾斜 ≤0.3°，95 分位 ≤0.8°；不得通过旋转整页来牺牲页边。
- **FR-006 管线集成**：预处理产物作为 OCR/版面还原的输入；保留 `original.jpg`，不覆盖原图。
- **FR-007 可观测**：输出 `preprocess.json`（四角、页边、行角、裁切框、耗时、回退原因），证据落盘。
- **FR-008 回归**：至少 10 张不同拍摄条件（平放/弯页/折痕/阴影/桌面背景）的样张；不得只对 `IMG_7544.jpg` 生效。

## 4. 非目标

- 不处理书脊另一页的完整展开（摊开书双页拆分由 `SpreadSplitter` 负责）。
- 不做内容识别/翻译；不改变 OCR 模型。
- 本周期不解决导出层「背景字与可编辑字未完全重合」的重影；该问题记录在 `TODO.md` 的 Deferred。

## 5. 验收标准

| 编号 | 指标 | 门槛 |
|---|---|---|
| SC-001 | 页外背景残留 | <2% 页面面积 |
| SC-002 | 页边直线度 | 最大偏差 ≤0.5% 短边 |
| SC-003 | 左右/上下边平行度 | ≤0.5% 短边 |
| SC-004 | 文字行角度 | 中位 ≤0.3°，95 分位 ≤0.8° |
| SC-005 | 内容不丢 | 原 OCR 字符召回 ≥99%；照片/插图裁切无非预期丢失 |
| SC-006 | 下游稳定 | 表格 3 列/2 列判定与基线一致或更好；Word/WPS SSIM 不低于当前 0.906 |
| SC-007 | 性能 | 单页预处理 ≤1.5s（iPhone 13，2200px 长边） |

## 6. 风险

- 页面分割把内页插图/深色边框误当页边 → 用文本墨迹包围盒 + 纸张色一致性双门控。
- 去折痕滤镜把照片/彩色插图洗白 → 用保留区 mask 排除 figure/artwork。
- 网格 dewarp 产生空白/拉伸 → 先做水平行矫正，再做垂直边界；每步有回退。
- iOS 26 设备 Vision 文档分割能力差异 → 允许回退，记录原因，不因单设备失败阻断。
