### P0 — 还原样张过关（本机优先）

验收仍用两张样张：练习册 Test 4、干燥芒果营养表。

1. ~~Dump 样张 OCR lines（text + bbox）固化为测试夹具。~~ **✅ 已完成（2026-09-07）**
   - `Tools/ocr-dump/` 三步工具链（导出 json → 生成 Swift 夹具 → 免 Xcode 校验断言）。
   - `ZhixiaTests/ReconstructV2Fixtures.swift`（真实 OCR 82 行 + ground truth）、
     `ReconstructV2Tests.swift`（15 测试 / 8 处已知失败已用 `withKnownIssue` 记录）。
   - 实测结论见 [07 §1.4](07-reconstruct-r2-optimization.md#14-实测数据m0-夹具2026-09-07)。
2. 修 `OnDeviceTableCluster`：营养表稳定 3 列，「能量|1429|17%」同行。
   - 已定位：`isCell` 放行包装噪声 → 列中心被带偏到 `[0.185, 0.378, 0.662]`（真值 `[0.175, 0.505, 0.815]`）。
3. 修 `OnDeviceFigureRegions` + 占用掩码：A/B/C 配图出齐；条码不抢走全部 figure 名额。
   - 已定位：两张样张当前均返回 **0 个**候选。
4. 阅读序 / 导出：Word 块顺序与大致版心接近原页（不必像素级 WYSIWYG）。
   - 已定位：`clusterRows` 同带阈值 ±0.02 取绝对值，导致 Section 1/2 颠倒、页眉抢标题位。
5. 手验「还原 → 导出 Word」；单测覆盖夹具。
