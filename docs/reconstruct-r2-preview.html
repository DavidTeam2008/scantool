还原 → 导出 Word · R2 原型

R2 把「还原」从「靠 Vision 一把梭」重构为「版面分析 → 块映射 → 锚点式导出」的三段流程；UI 上对应三档产物可切换，并把失败空态、场景选择、修复提示分开。本页是 UI 改版与流程的可视化方案。

2. 新用户流程

详情底栏「还原」点进，进入 R2 还原页：

① 本机解析（默认）→ 成功：进入预览；失败：失败空态
② 预览：上半原图 / 下半 block 流；右上可切换档位
③ 场景选择：自动识别不对时手动指定
④ 修复：面板列出本次解析出问题的小项（题图缺失、表头被拆等）
⑤ 导出：档位 A / B / C 三选一 → 出 Word / 可检索 PDF

4. 现状 vs R2

现状（R1）

  • 单管线：OCR → 表 → 阅读序 → 图 → 按 Y 排序 → DOCX
  • 配图：36×48 栅格、文字 inset 0.018
  • DOCX：段落 + 表格 + inline 图
  • 无档位、无场景选择、失败只显示通用文案

R2 目标

  • 三段管线：版面分析 → 块映射 → 锚点式导出
  • 配图：72×96 栅格 + 显著性 + 题下 anchor
  • DOCX 三档：A 流式 / B 锚点 / C 衬底图
  • 场景选择 + 修复提示 + 失败空态引导

5. 文档结构示意（A 档 DOCX）

[Content_Types].xml _rels/.rels word/ document.xml ← 内流式段落 + w:tbl + wp:inline 图 styles.xml _rels/document.xml.rels media/ image1.png ← 营养表的条码裁切 PNG document.xml 结构： <w:body> <w:p> ← 包装说明段（heading） <w:p> ← 配料、保质期（paragraph） <w:p> ← 表标题「营养成分表」 <w:tbl> ← 三列网格（col widths 按 OCR 推） <w:tr> ← 表头加粗 <w:tr> 能量|1429 千焦|17% <w:tr> 蛋白质|1.5 克|3% <w:tr> 脂肪|0.8 克|1% <w:tr> 碳水化合物|80.8 克|27% <w:tr> 钠|49 毫克|2% </w:tbl> <w:p><w:drawing><wp:inline .../> ← 条码图 <w:p> ← 题注「6936832529010」 <w:sectPr/> ← A4 </w:body>

B 档：用 wp:anchor + w:positionH/V 让图按页面绝对位置落位；C 档：在背景层铺一张原图 full-page。

6. 设计原则

产品定位

「还原」默认本机、不上传；R2 增加可切换产物的三档，让用户按场景选择。

失败可见

失败空态给出可能原因与修复入口；不仅「失败」。

隐私默认

云解析永远需要用户主动确认单页并明示披露。
